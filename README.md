
# Проект №3. Страница блога

Учебный проект Яндекс Практикума на React и TypeScript.

## Что изменилось относительно main

- Добавлена выдвижная панель настройки оформления статьи.
- Добавлен выбор шрифта и размера текста.
- Добавлен выбор цвета текста и фона.
- Добавлен выбор ширины контента.
- Реализованы кнопки «Применить» и «Сбросить».
- Добавлено открытие и закрытие панели по кнопке и клику за её пределами.
- Реализовано сохранение черновика настроек при закрытии панели.
- Доработаны UI-компоненты и их взаимодействие.
- Добавлены браузерные тесты Playwright (17 сценариев).

## Запуск проекта

Требуется Node.js 22.15.0 или новее.

```bash
npm ci
npm start
```

После запуска открыть в браузере:

http://localhost:8080
